# Проверка перед передачей

- Python 3.13, зависимости из requirements.lock.txt.
- 22 автоматических теста: PASS.
- Проверка JS синтаксиса и компиляции Python: PASS.
- Chromium 390×844: каталог, форма, подтверждение, избранное, профиль, обработка данных, загрузочный экран; дополнительно каталог при 1280×900.
- Проверены реальные действия в локальном браузере: отправка заявки, сохранение в SQLite, переход в историю; добавление в избранное и открытие карточки; привязка товара, загрузка фото, отправка и просмотр приватного фото в истории.
- В браузерном прогоне нет ошибок JavaScript и горизонтального переполнения.
- Просмотрены изображения экранов, исправлены двойная рамка поиска, неподдерживаемый значок, положение кнопок подтверждения.
- Логика отправки менеджеру и изменения статуса проверена с имитацией Telegram API.

## Что не проверялось без настроек владельца

- Реальная отправка сообщений/фото Telegram и запуск внутри Telegram на телефоне.
- Получение сертификата Caddy, DNS, Docker-сервисы на настоящем VPS.
- Работа с настоящими товарами и правила магазина.

Тестовый товар и тестовые заявки использовались только в отдельной локальной базе проверки. В архив они не включены. Проект не публиковался в интернете.
